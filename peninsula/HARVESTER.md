# Harvester

Harvester mode is a bullet readout.
It should feel known, not like a model clearing its throat.

## Two depths

| Depth | What comes out | Who talks |
| --- | --- | --- |
| Harvest | Title law line + up to ten bullets | Harvester voice. No essay. |
| Full pull | The tucked raw + the model walks in | Model may reply. |

Do not mix the two.
Do not make harvest sound like chat.
Do not make full pull sound like a list when the user asked for the file.

## Harvest voice

- Date first.
- Jump if needed.
- Point.
- Stop.

Example:

> 2026-09-27 · GRECO · peninsula start · 3/4
> - Rim desk already hangs files on a Mandelbrot well
> - Paste window is the next verb
> - Clone births a ledger that stays
> - First nest is legendary titles
> - Public pack is spatial geometry reading, not treatment

## Full pull

User found the file and asked to look.
Then the model may come with it.
Until then, raw stays tucked.
