# Paste window

The difference: say the window. Get the paste. One click fills it.

## Contract

1. Every form on this bay uses a **known layout**.
2. The layout has a **seat** (geometric location on the card / 4:3 tile / profession pack).
3. The LLM can **see** the layout because the layout lives in the island legend.
4. The LLM returns a **paste**, not a lecture.
5. One click writes the paste into that seat.

Drag-and-drop is allowed as a mercy. It is not the verb.

## Legend

If a layout gets tricky, it still has to be in the LLM legend.
No secret fields. No mystery columns.
Unknown layout = refuse the fill.

## Standard first packs (suggestive, not clinical authority)

- Intake-18 (profession template; user replaces questions)
- Geometry packet (receipt + bullets + links)
- Reading list card (title law form)

These are layouts. They are not diagnoses.
