# Glossary

Keep this short. Same word, same seat.

- **Bay** — the project. Mandelbrot, not Mandalay.
- **Peninsula** — first land. This folder.
- **Rim** — hang circle around the well.
- **Well** — the Mandelbrot canvas.
- **Seat** — geometric location of a card or field.
- **Nest** — canvas stepping down a layer. First nest = legendary titles.
- **Island** — one clone / one download. Owns one ledger.
- **Ledger** — append-only title store. Does not leave the island.
- **Legendary title** — a title that stayed. Project name, approved bullets, or inbound MD title.
- **Paste window** — known layout + one-click fill from an LLM paste.
- **Legend** — the layout map the LLM is allowed to see.
- **Harvester** — bullet readout mode.
- **Full pull** — open the tucked raw; model may speak.
- **Tucked raw** — the real file body. Not harvested until asked.
- **Jump unit** — spoken time skip in a title.
- **4:3 / 3:4** — white-tile ratio after descend.
- **Geometry packet** — receipt of discovery. Not a treatment claim.
